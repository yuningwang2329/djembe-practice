## 谱面结构

| 段落 | 展开小节 | 处理 |
| --- | --- | --- |
| 谱外引子 | 0–10.61 秒 | 只播放原音频，不编造鼓点 |
| 前奏 | 1–8 | 基本型 ×6、加花、单 B 收束 |
| 主歌一 | 9–24 | 基本型 ×7 + 加花，整体 ×2 |
| 副歌一 | 25–40 | 轻击型 ×7 + 副歌加花，整体 ×2 |
| 间奏一 | 41–48 | 轻击型 ×7、单 B 收束 |
| 主歌二 | 49–64 | 同主歌一 |
| 间奏二 | 65–80 | 单 B + 全休止 ×15 |
| 副歌二 | 81–112 | 八小节组 ×3，再轻击型 ×6、加花、单 B |
| 尾奏 | 113–128 | 全休止 ×8，基本型 ×6、加花、结尾 |

三音节奏按下划线转录：BSS/Bss/Sss = 八分 + 十六分 + 十六分；SSB = 十六分 + 十六分 + 八分；sSBs/SsBB = 四个十六分。末小节 `B Bb 0 0` 的第二拍按一强一轻两个八分记录；原图此处连线不清晰，这一拍时值仍可结合原教学复核。

## 录音节拍证据

采用 118 BPM、第一小节 10610 ms；时间为录音绝对毫秒，`audioOffsetMs = 0`。全部时间由拍位统一生成，不逐拍累积取整。

先在 116–120 BPM 范围搜索相位和速度，再按瞬态峰拟合。低频 35–180 Hz、高频 1800–8000 Hz 分别检验；1024 点 Hann 窗、110 点步长、22050 Hz 单声道。前 100 秒用于拟合，中后段作为留出检查。

- 低频前段拟合约 118.0019 BPM，高频约 118.0028 BPM，均支持采用 118，而不是有意义的全曲速度变化。
- 低频 10–100 / 100–180 / 180–270 秒的误差中位数约 1.4 / 1.4 / 2.2 ms，P90 绝对误差约 7.4 / 10.2 / 8.6 ms。
- 高频相对低频约早 8 ms，属于不同频段起音特征；不能重复据此移动谱面。

这些证据支持节拍网格稳定，不证明每个改编鼓音都与原录音乐器逐音相同。峰值筛选在候选拍点附近进行，不能单独证明第一拍相位；段落定位还结合了谱面反复和所给 LRC。

复查脚本：`scripts/check-recording-grid.py`，依赖 numpy。先用本地 ffmpeg 解码为单声道 22050 Hz PCM16 WAV，然后运行：

```sh
python3 scripts/check-recording-grid.py recording.wav --bpm 118 --start-ms 10610 --end 270
```

## 歌词与证据边界

保留用户 LRC 的 24 句及原起始时间，去除作词、编曲等非演唱元数据。句尾为显示用估计，在间奏和尾奏留白，不将整段空白填满上一句。字符按句时长展开，非真实逐字时间。

没有声称完成逐句人工听校或真实 iPad 听感验收。特别是 LRC 最后三句起点 204、212、224 秒，保留输入而不假装秒级数据有毫秒精度。后续歌词微调只改独立 cue，不移动鼓谱。
