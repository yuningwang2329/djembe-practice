# 竖线居中修正

最新要求：B 放大时竖线正好在 B 中心，不再主动超前。

## 原因与修改

- 旧版固定提前 0.48 拍，但字母居于自身音符格中心：整拍中心在半拍处，八分和十六分的中心更靠前。因此同一提前量无法兼顾所有音符，细分鼓点会明显越过中心。
- 改为连接“实际击响毫秒 → 该音符渲染格中心”的锚点，连续插值，并跨小节连续移动。原有字母位置、音符放大时刻、录音与鼓声调度不变。
- 默认额外提前量为 0，使用新的设置键，不继承旧版本设备上保存的提前量。仍保留手动微调。
- 歌词继续随竖线文字扫色；不恢复歌词横线或第二根竖线。

## 验证

- 全曲库逐个渲染鼓点核对中心锚点，包含变速和变拍号。
- 桥边姑娘、鼓楼按真实鼓点时间取首部、中部和尾部的四分、八分、十六分样本；横屏和竖屏实际浏览器测量字母与竖线中心，要求误差小于 1.5 CSS 像素，全部通过。
- 146 项单元/组件测试、29 项浏览器测试通过，类型检查和生产构建通过。
- 本次仅验证视觉投影，不宣称重新完成所有歌曲的听觉对拍或真实 iPad 声音输出延迟验收。
