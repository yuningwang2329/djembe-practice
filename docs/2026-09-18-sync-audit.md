# 桥边姑娘同步修复与发布报告

日期：2026-09-18。修改对象：Kimi 后续维护的 djembe-practice，分支 main。

## 本次交付

修正确定存在的 3.111 秒重复偏移，将歌词从固定小节分配改为独立时间轴，并保持原有三行鼓谱、R/L、音轨开关、变速和循环操作。

网站入口：https://yuningwang2329.github.io/djembe-practice/
推送 main 后由仓库 Deploy to GitHub Pages 工作流自动发布。部署是否完成应以工作流结果及线上资源版本为准。

## 确定的问题及修复

- 旧版 bars/hits 已加 3111ms，createAudioClock 又减去 song.audioOffsetMs=3111，造成谱面和鼓声对应的录音时刻晚 3111ms。现在本曲明确使用录音绝对毫秒，audioOffsetMs=0，保留首鼓点 3111ms。
- 旧版歌词按短句固定两小节分配，遗漏中间间奏和第二段过渡重复。改为独立歌词事件，保留起止时刻；渲染层按实际事件与谱面行的时间交集摆放，并高亮当前句。
- 参考时间戳来自 https://www.9ku.com/play/1000452.htm ，文本复用本项目已有文本。末句结束 162500ms 是显示区间估计，并非听校标注。段落标签为参考乐句所在小节的提示。

## 试听检查点

从原录音时间 17.18、56.76、97.98、137.45 秒附近依次复核首段、首副歌、第二段、末副歌；90 秒附近应无当前歌词。若四处同向偏移，先校准歌词整体偏移；若偏差随时间变化或句子不同，应重新标注逐句时刻，不能再以固定两小节补齐。

## 网站更新后如何检查

1. 联网打开网站；若显示新版本提示，暂停后点击刷新更新。安装到主屏幕的版本也需要联网获取更新。
2. 打开《桥边姑娘》，使用原来导入的 FLAC；这次更新不删除 IndexedDB 中的本地歌曲。
3. 正常速度下检查上述四个时刻，以及约 90 秒间奏没有当前歌词高亮。
4. 分别关闭原歌曲和示范鼓声，再试 0.5/1/1.5 倍速、小节循环和拖动进度。
5. 若还有错位，记录原歌曲进度、屏幕歌词与实际唱到的句子，便于对这份录音继续校准。当前结果不包含逐句人工听校的保证。
