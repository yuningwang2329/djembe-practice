# 鼓点练习

一个给家人使用的 iPad 横屏非洲鼓练习 PWA。它把原歌曲时间作为谱面主时间轴，同时播放可独立开关的示范鼓声，并支持 R/L 左右手、B/T/S 鼓音、倍速、循环、倒数、屏幕常亮和离线重开。

## 已实现

- iPad 横屏四小节谱面，竖屏仍可操作并提示旋转。
- 低音 B、开音 T、掌击 S，以及每个鼓点的 R/L 左右手。
- 原歌曲与示范鼓声分别开关、分别调音量。
- 0.50× 到 1.50× 倍速，步进 0.05×，保持音高。
- 自选起止小节循环，首次播放一小节倒数。
- 播放、暂停、拖动和循环后重新同步；播放时申请屏幕常亮。
- 从 iPad“文件”App 导入 MP3、M4A 或 AAC；检查可解码性、时长和剩余空间。
- 导入歌曲保存在浏览器 IndexedDB 中，不上传，也不会放进 GitHub。
- 应用外壳、示例谱、图标和无版权示例伴奏离线缓存；更新失败时继续使用旧版本。
- 自带 16 小节、32 秒的“暖身律动”示例。

## Mac 本地运行

需要 Node.js 20 或更高版本。在项目目录执行：

```bash
npm install --cache .npm-cache
npm run dev
```

如果希望 Mac 在本地预览期间保持常亮，可以直接用：

```bash
caffeinate -d -i -m npm run dev
```

终端会显示局域网地址。iPad 和 Mac 连到同一个 Wi-Fi 后，可在 iPad Safari 打开该地址做功能预览。

局域网 HTTP 只适合预览。iPad 的“添加到主屏幕”、Service Worker 离线缓存和完整屏幕常亮能力需要正式 HTTPS 地址。

## iPad 正式使用

1. 用 Safari 打开部署后的 HTTPS 地址。
2. 等首页显示“已可离线使用”。
3. 点 Safari 分享按钮，选择“添加到主屏幕”。
4. 从主屏幕打开“鼓点练习”，横屏放置。
5. 进入曲目，点“导入原歌曲”，从“文件”App选择对应音频。
6. 看到“已保存到此 iPad · 离线可用”后，可开启飞行模式再重开验证。

删除 Safari 网站数据、移除浏览器数据，或系统在极端空间不足时清理网站数据，可能需要重新导入歌曲。应用会主动请求持久存储，但最终是否授予由 iPadOS 决定。

## 增加新歌曲

谱面数据使用 `SongDefinition`，每个鼓点保存歌曲中的精确毫秒时间、鼓音和左右手。增加歌曲只需要新增曲目数据，不需要改播放器结构。

真实商业歌曲只在家人的 iPad 上导入。`.gitignore` 已屏蔽 MP3、M4A、AAC、FLAC 和 `user-audio/`，不要把真实歌曲复制到 `public/`。

后续你把歌曲和希望的难度发给我，我会制作对应的鼓谱数据并校准 `audioOffsetMs`。不同剪辑版本的歌曲时长可能不同，导入时出现时长提醒应先确认版本。

## GitHub 与部署

首轮本地验收不需要 GitHub。确认界面和练习方式后，再创建一个空的私有 GitHub 仓库并提供仓库地址即可。

GitHub 只保存源码和谱面。国内家庭长期入口应部署到有 HTTPS 的静态托管；如果使用中国内地服务器和域名，需要按实际服务商要求处理备案。GitHub Pages 不作为国内长期入口。

原生 Service Worker 会在每次生产构建时根据输出文件自动生成新的缓存版本，程序更新不会删除 IndexedDB 中已经导入的歌曲。
